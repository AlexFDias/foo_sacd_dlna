### DVD-Audio → FLAC: official encoder

DVD-Audio conversion now has **one FLAC writer only**: the official libFLAC 1.5.x encoder. The former hand-written FLAC encoder was removed to avoid orphaned code between revisions. The component feeds interleaved 24-bit PCM to libFLAC, which owns STREAMINFO, frames, subframes and CRC generation. Cache validation no longer assumes the old writer's internal frame layout.

`cacheVersion` is now **4**, automatically invalidating caches generated by the previous hand-written writer.

See `docs/ARCHITECTURE.md` for the DVD-Audio FLAC pipeline, cache-availability, media-diagnostics and stream-limiter implementation notes, and `CHANGELOG.md` for their revision history.
